# LumaPlayer 3.3.7.1 exp

Основа 0.3.3.7 exp. В 1080p профиль N задаётся файлом engine/gpu/io1080.profile. O включает запись результата в staging с барьером перед чтением CPU. N переносит нормализацию результата в GPU-шейдер. I включает чтение входного staging шейдером. Пустой файл возвращает прежний путь. Закройте и запустите пререндер после изменения профиля. Для запуска нужна вся папка рядом с EXE.

На Arcane S02E05 все четыре экспериментальные комбинации O, N, I и ONI совпали с эталоном на 120 кадрах RGB до кодирования. Проверка с физическим экраном на 30–38-й минутах с начальным запасом 30 с использовала отдельный mpv и громкость 0. Скорость 1.0969×, остановок 0, пропусков 1, минимальный запас 17.50 с. Полные результаты в source/validation-io1080. Статус допуска к выдаче: True.
