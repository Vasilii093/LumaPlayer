# LumaPlayer 0.3.3 exp — исходники экспериментальной версии

Текущая рабочая основа — LumaPlayer 0.3.3 exp: локальная переносимая сборка в `work/LumaPlayer-0.3.3-exp` рабочей области Codex. В оконном режиме заголовок скрывается после бездействия и появляется у верхнего края; шкала показывает время под указателем. Сохранены RIFE 4.6, обработка 1080p, кэш VapourSynth 1024 МиБ и цель запаса до 240 секунд.

В 1080p используется `rife-memory`. Для трёх слоёв Concat работает экспериментальный шейдер прямой сборки pack4 с проверкой входного формата и запасным штатным путём. Изменённые файлы ncnn находятся в `source/experimental-concat/`; исходники RIFE — в `source/native-rife-memory/`. Вулкан → NVENC GPU-direct не встроен.

**Важно:** сохранённый в корне `LumaPlayer.exe` и `package-manifest.json` относятся к прежней версии **0.3 exp** и не содержат эти изменения. GitHub содержит обновление исходников для анализа, а не готовый комплект 0.3.3 exp. Запуск и сборка требуют локальный переносимый комплект с зависимостями, моделью и экспериментальной DLL. SHA-256 локального EXE 0.3.3 exp: `1e3122fdbb303b4c979a8c1547002eb7ab6934db7faf2cf4d10a360fe2437360`; экспериментальной DLL: `591ca56038ea84b3ef48ece6d71a6722ead9432fac70abf9e6b3153834bdb68f`.

## Проверки и ограничения

На последнем 90-секундном тесте 1080p60 с физическим экраном и отдельным mpv скорость подготовки составила 0,831×, остановок и пропусков не было, минимальный запас — 2,68 с. Это один прогон без звука; стабильная работа выше 1× и запас 20–30% не подтверждены. На предыдущей рабочей копии пользователь сообщал о колебаниях 0,95–1,17× на протяжении восьми минут тяжёлого видео. Подробности: `docs/ИСПЫТАНИЯ-0.3.3-exp.md` и `docs/ИСПЫТАНИЯ-CONCAT.md`.

Сохраняется условие пользователя: не выпускать версию при результате ниже 1×. Исследование повышения скорости продолжится отдельно.
