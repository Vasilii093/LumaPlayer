# LumaPlayer 1.0.1 stable

Windows-плеер с RIFE 4.6. Добавлены режимы 720p90 и 900p72. Для их работы откройте видео, выберите режим и нажмите «Подготовить кэш». Режим 900p90 в эту версию не включён.

Результаты по три минуты Arcane S02E05 30:00–33:00 на физическом экране (отдельный mpv, звук заглушён, начальный запас 30 секунд): 720p90 1,113×, 0 остановок буфера, 1 пропуск вывода; 900p72 1,365×, 0 остановок и 0 пропусков вывода. Синхронизация с экраном отключена. Режимы дополнительно проверены в плеере со звуком WASAPI. Результаты относятся к указанному материалу и не гарантируют такую скорость на всех видео. Проверка находится в source/validation-stable101.

Скачанный архив распакуйте целиком и запустите LumaPlayer.exe. Исходники находятся в source, скрипт сборки — source/build.ps1.
