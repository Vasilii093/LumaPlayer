# LumaPlayer 1.1.0 stable

Переносимый Windows-плеер с RIFE 4.6. Распакуйте архив целиком в доступную для записи папку и запустите LumaPlayer.exe.

## Изменения 1.1.0

- На основной панели рядом доступны «Звук» и «Изображение».
- Ползунки яркости, контраста, насыщенности, гаммы, GPU-резкости, усиления и эквалайзера применяются сразу.
- По четыре готовых пресета и по три пользовательских слота отдельно для звука и изображения.
- Пользовательские пресеты и последние настройки восстанавливаются после запуска. Файл settings/adjustments.json создаётся рядом с EXE; сохраняйте папку settings при обновлении.
- Кнопка «Ссылка» / Ctrl+Shift+O и запуск с HTTP/HTTPS URL первым аргументом.
- Удалены недоступные ветви старых моделей и неиспользуемые варианты сборки.

## Настройки

Для записи пресета настройте ползунки, выберите слот в нижнем списке и нажмите «Сохранить». Верхний список загружает пресет. «Сбросить» обнуляет текущую обработку, не удаляя записанные пресеты. Последние значения сохраняются при закрытии окна настроек. Изображение корректируется при выводе, исходное видео и дисковый кэш не переписываются.

Профили: исходное видео, RIFE 720p60, кэш 720p90/900p60/900p72/1020p60 exp/1080p60. Модель, качество кодирования и настройки параллельности 1080p сохранены: эксперимент с приростом около 3% не включён.

## Сетевые источники

Принимаются прямые HTTP/HTTPS-ссылки. Для сети используйте исходное воспроизведение или RIFE 720p60; подготовка дискового кэша отключена. Второй запуск не передаёт URL уже открытому экземпляру. Авторизация сервисов, DRM, прямые эфиры и страницы сайтов не заявлены как поддерживаемые. Проверка выполнена по HTTP на локальном сервере; HTTPS отдельно не проверялся. Журналы могут содержать URL с токенами — проверяйте их перед отправкой.

## Проверки и исходники

Проверены цветовые параметры и GPU-резкость во всех семи режимах, сброс, живые события ползунков, пользовательский пресет и восстановление после запуска. HDR, длительные испытания и влияние коррекции на производительность отдельно не измерялись. Исходники и журналы тестов находятся в source. Для сборки EXE используется source/build.ps1 и компилятор .NET Framework x64. Нативные DLL и веса входят в ZIP.
