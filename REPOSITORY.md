# LumaPlayer 1.0.1 stable

История версий, описания и ссылки на файлы находятся в [VERSIONS.md](VERSIONS.md). Ветка `versions` содержит текущие исходники. Полный переносимый комплект с движком, DLL и весами находится в ZIP релиза; извлеките архив целиком. `package-manifest.json` описывает полный комплект релиза.
